# ============================================================
# 手工影视源清单（网页直接提交）
# ============================================================
# 使用方法：
#   1. 在 GitHub 网页上点开本文件，点右上角铅笔图标（Edit）
#   2. 在下方空行处粘贴新的影视源地址，一行一个
#   3. 拉到页面底部点 Commit changes
#   4. 保存后会自动触发测活并更新订阅（约 3-5 分钟），无需手动点 Run workflow
#
# 说明：
#   - 每行一个地址，支持 http:// 和 https://
#   - 以 # 开头的行为注释，会被忽略
#   - 删掉某行即可移除该源
#   - 这里只放你信任、有权访问、内容合规的地址
# ============================================================
